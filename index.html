Python-Shape-Generator

One small Python file, python-shape-gen.py, that prints five shapes in the terminal at a size I pick. This page is the workbook sheet for it: the shapes are printed below as plates, with the text of the chapter running alongside.

The repo banner, shown at the top of the sheet the way a workbook prints its chapter heading picture.

Ch. 1What this is

I wrote this to draw shapes out of text characters in a terminal. I run it, I type the name of one of five shapes exactly as the program lists it, and I give it a size. It prints the shape and stops. There is no window, no file output, and no import in the file at all.

The five names are Square, Rectangle, Lower Left Triangle, Upper Left Triangle, and Diamond. Four of them draw with the @ character. The diamond draws with #, a split that was in my first version and that I kept on purpose, so a diamond stands out from the rest of the page.

Each shape has its own draw function, and all of the asking happens in main() and in read_size(). That split matters to me: I can import the file and call draw_diamond(3) on its own, and no prompt gets in the way.

Margin note: the plates in Chapter 2 are not drawings of the output. They are the output, copied line for line from my runs on this head.

Ch. 3Lines from the file, checked

I copied these excerpts straight from python-shape-gen.py at head 504640b. The numbers on the left are the line numbers in that file.

The list I have to spell exactly. Lines 12 to 13:

12  CHOICES = ["Square", "Rectangle", "Lower Left Triangle",
13             "Upper Left Triangle", "Diamond"]

The lower left triangle, with the off by one fix in it. Lines 77 to 78:

77      for row in range(size):
78          print("@" * (row + 1))

A size of 0 or less gets refused and asked again. Lines 43 to 49:

43          if value < 1:
44              # I reject 0 and negative sizes here. A size of 0 would draw
45              # nothing and look like a silent failure, so I say so and ask
46              # again instead.
47              print("Please enter 1 or more.")
48              continue
49          return value

The diamond lower half, which starts at radius minus 2 so the widest row prints once. Lines 98 to 106:

98      for row in range(radius):
99          print(" " * (radius - row - 1) + "#" * (2 * row + 1))
100      # I start the lower half at radius - 2, not radius - 1. Radius - 1 is
101      # the middle row, and the loop above already printed it. If I started
102      # here at radius - 1, the widest row would print twice.
103      # Edge case I checked: radius 1 makes this second range empty, and
104      # the whole diamond is just the single "#" from the first loop.
105      for row in range(radius - 2, -1, -1):
106          print(" " * (radius - row - 1) + "#" * (2 * row + 1))

Run it yourself from the repo root:

python3 python-shape-gen.py
  • Type a shape name exactly as listed. A close spelling gets: Invalid choice please enter correctly, and I ask again.
  • Text for a size, such as abc or 3.5, gets: Please enter a whole number.
  • Closing the input at a prompt ends the program cleanly, with no traceback.
  • Radius 1 for the diamond prints a single # and nothing else.
