Python-Shape-Generator

The display case itself, one pan per shape the script can draw. python-shape-gen.py is an interactive script. Run it with python3 python-shape-gen.py, and it shows a list of shapes, asks you to type one name exactly, then asks for a size, then draws the shape on screen out of typed characters. There is no window and no file output, and each shape has its own draw function, with all of the asking kept in main() and read_size().

Diamond

One prompt: Radius. Drawn in hash marks, the only shape that changes character. A line announces the diamond before it appears, and the points are built from odd counts of marks, one, three, five, centred with leading spaces.

How a visit goes

The script opens with Welcome to the shape maker! and prints its list with brackets and quotes, just as Python prints a list:

['Square', 'Rectangle', 'Lower Left Triangle', 'Upper Left Triangle', 'Diamond']

Type one of those names exactly, capitals and spaces included. A name that is not on the list earns the reply Invalid choice please enter correctly and another try. A size typed as letters or as a fraction earns Please enter a whole number.. Zero or below earns Please enter 1 or more.. Closing the input ends the program quietly, with no error shown.

One last scoop: the drawing routines can be imported and called on their own, for instance draw_diamond(3), without the prompts, because importing the file runs nothing. The sheets in the visuals folder and the code itself sit in the repository.
