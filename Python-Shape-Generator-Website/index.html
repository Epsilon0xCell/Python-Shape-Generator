Python-Shape-Generator

Five ASCII shapes drawn in the terminal at a size you pick.

What this is

I wrote a small stdin-driven script, python-shape-gen.py, that draws one of five shapes and then stops. You type the shape name exactly as listed, then a size.

Each shape lives in its own draw function and all input lives in main() and read_size(). That split means I can import the file and call draw_diamond(3) on its own, with no prompts in the way.

The exhibits below are not drawings of the output. They are the output. I ran the script for each shape and copied what it printed.

The gallery

Run it

python3 python-shape-gen.py

Pick one of the five shapes by its exact name (Square, Rectangle, Lower Left Triangle, Upper Left Triangle, Diamond), then give it a size. Rectangle asks for a width and a height; the others ask for one side length or radius.

Honest notes

A bad size no longer ends the program. Text like abc gets "Please enter a whole number." and a second chance. Closed stdin ends cleanly with no traceback. A bad shape name re-prompts instead of guessing.
